# 아키텍처 이미지 오타 수정 요청

이미지 안에 박힌 글자라 **코드에서 고칠 수 없습니다.** 원본 파일(PPT·Figma 등)에서 수정 후
PNG로 다시 내보내 주시면 교체하겠습니다.

## 수정 목록

| # | 파일 | 현재 | 수정 |
|---|---|---|---|
| 1 | `architecture-solution.png` | 보만 시스템 연계 | **외부 시스템 연계** |
| 2 | `architecture-solution.png` | 기타 외책 시스템 | **기타 외부 시스템** |
| 3 | `architecture-devenv.png` | 개발환경 아키텍쳐 | **개발환경 아키텍처** |

> 3번 `개발환경 아키텍쳐` → `개발환경 아키텍처` — 표준 표기는 **아키텍처**입니다.
> 같은 도면 묶음의 다른 두 장은 이미 `아키텍처`로 되어 있어 표기가 어긋나 있습니다.

## 우선순위

**1·2번이 우선입니다.** `architecture-solution.png`는 현재 공개 사이트의 아키텍처 섹션에
노출되고 있고, 라이트박스로 확대해서 볼 수 있어 오타가 그대로 읽힙니다.

**3번은 급하지 않습니다.** `architecture-devenv.png`는 GitLab 저장소명·브랜치 전략·CI/CD 구성 등
사내 인프라 정보가 담겨 있어 **공개 사이트에서 제외**했고, `public/` 디렉터리에서도 파일을 삭제했습니다.
사내 문서용으로만 쓰신다면 표기 통일 차원에서만 고치면 됩니다.

## 교체 절차

1. 수정된 PNG를 전달 (원본과 같은 1536 × 1024 권장 — 다른 크기여도 되지만 알려주십시오)
2. `public/images/architecture-solution.png` 를 덮어쓰기
3. 크기가 바뀌었다면 `content/site.ts` 의 `ARCHITECTURE_VIEWS` 에서 `width` · `height` 수정
4. 재배포

> 파일명이 바뀌면 `content/site.ts` 의 `src` 도 함께 수정해야 합니다.

## 함께 확인하면 좋을 것

교체하는 김에 아래도 봐주시면 좋겠습니다.

- 도면 안 영문 표기 통일 (`Data Warehouse` / `데이터 웨어하우스` 혼용)
- 텍스트 크기 — 현재 원본에서도 작은 글자가 있어, 라이트박스로 확대해도 읽기 어려운 항목이 있습니다
